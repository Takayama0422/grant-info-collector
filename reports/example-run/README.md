## 中身の見方

- `grants.csv` — Excel でそのまま開ける（BOM付きUTF-8）。**末尾の `#` 始まりの行**は出典・加工主体の記載
- `grants.xlsx` — 1枚目が一覧（107行）、2枚目「出典・利用条件」が出典・加工主体の記載

**金額・受付開始日・受付締切日の3列は空欄である。**
出典側のカタログにその項目が無いためで、推定値は入れていない（`docs/compliance.md` 1-4 参照）。

## 同じ結果を手元で出す方法

```bash
npm ci
npm run collect            # ネットワーク取得（約2分。相手に10秒間隔を空けるため）
npm run collect:offline    # 通信なし。同梱の固定データから同じ107件を約0.5秒で再生成
```

通信ありと通信なしで**同じ107件**が出ることを確認済み（並び順のみ出典側の並びに依存する）。
